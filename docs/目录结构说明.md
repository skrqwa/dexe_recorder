# dexe_recorder 目录结构说明

> 更新: 2026-07-06

## 顶层目录

```
dexe_recorder/
├── CMakeLists.txt          # CMake 构建配置
├── package.xml             # ROS2 包描述文件（依赖、元信息）
├── build.sh                # 编译+打包脚本（colcon build → install.tar.gz）
├── install.sh              # 部署脚本（install/ → debian 包结构）
├── README.md               # 模块说明
├── .gitignore              # 忽略 build/install/log/release
├── config/                 # 配置文件
│   └── auto_recorder.yaml  # 录制配置（话题、路径、缓冲、分段）
├── include/dexe_recorder/  # 头文件
│   └── recorder_node.h     # 节点类 + Frame 结构 + FrameBuffer 队列
├── src/                    # 源文件
│   ├── dexe_recorder_node.cpp  # main 入口
│   ├── recorder_node.cpp       # 节点实现（订阅/服务/写盘/JSON解析）
│   └── frame_buffer.cpp        # 线程安全有界队列
├── build/                  # colcon 编译中间产物（gitignore）
├── install/                # colcon 安装产物（可部署）
├── log/                    # colcon 编译日志（见下文）
└── release/                # 打包产物 install.tar.gz（gitignore）
```

## config/auto_recorder.yaml

录制节点的运行配置，包含：
- 数据源话题：`state_topic`、`head_left_topic`、`head_right_topic`、`hand_left_topic`、`hand_right_topic`、`ee_left_topic`、`ee_right_topic`
- 存储路径：`output_dir`（默认 `data/recorded_auto`）
- 帧缓冲大小：`max_buffer_frames`（默认 600，满了丢最旧帧）
- 单段最大时长：`max_segment_duration_sec`（0=不限）

运行时通过参数加载：`ros2 run dexe_recorder dexe_recorder_node --ros-args -p config:=config/auto_recorder.yaml`

## log 目录（colcon 编译日志）

`log/` 是 **colcon 自动生成的编译日志目录**，不是运行时日志。所有 ROS2 colcon 包都有此结构。

### 目录结构

```
log/
├── COLCON_IGNORE                              # 空文件，告诉 colcon 忽略此目录不当作包
├── latest -> build_2026-07-06_15-43-41/       # 软链，指向最近一次编译
└── build_2026-07-06_15-43-41/                 # 按编译时间戳命名
    ├── events.log                             # colcon 编译事件流
    ├── logger_all.log                         # colcon 自身调试日志
    └── dexe_recorder/                         # 该包的编译输出
        ├── streams.log                        # cmake/make 完整输出（编译错误排查首选）
        ├── command.log                        # 执行的 cmake/make 命令行
        ├── stdout.log                         # cmake/make 标准输出
        ├── stderr.log                         # cmake/make 标准错误（编译报错看这里）
        └── stdout_stderr.log                  # stdout+stderr 合并
```

### 各文件说明

| 文件 | 内容 | 用途 |
|------|------|------|
| `events.log` | colcon 编译事件（JobQueued/JobStarted/Command/完成） | 排查编译流程卡在哪 |
| `logger_all.log` | colcon 内部 DEBUG 日志（参数解析、包发现） | colcon 自身问题排查 |
| `dexe_recorder/streams.log` | **最全**：cmake configure + make 编译完整输出 | 编译错误排查首选 |
| `dexe_recorder/command.log` | 实际执行的 cmake/make 命令行 | 复现编译命令 |
| `dexe_recorder/stdout.log` | cmake/make 标准输出 | 查看编译进度 |
| `dexe_recorder/stderr.log` | cmake/make 标准错误 | **编译报错看这里**（0 行=无错） |
| `dexe_recorder/stdout_stderr.log` | stdout+stderr 合并 | 一次性看全部输出 |

### 要点

1. **编译日志，非运行日志**：节点运行时的 `[INFO]` 日志走 ROS2 日志系统（输出到终端或 `/rosout` 话题），不写到这里
2. **每次 `colcon build` 新建时间戳目录**，`latest` 软链指向最新一次
3. **`COLCON_IGNORE`** 是空文件，防止 colcon 把 `log/` 当成 ROS 包扫描
4. **`.gitignore` 已忽略 `log/`**，不会进 git

## build 与 install 目录

### build/

colcon 编译中间产物（CMake 缓存、对象文件、链接中间文件），可安全删除（`rm -rf build && ./build.sh` 重新全量编译）。已被 `.gitignore` 忽略。

### install/

colcon 安装产物，可直接部署运行：

```
install/dexe_recorder/
├── lib/dexe_recorder/dexe_recorder_node              # 可执行文件
└── share/dexe_recorder/
    ├── config/auto_recorder.yaml                     # 配置文件
    ├── local_setup.bash                              # source 脚本
    └── package.xml                                   # 包描述
```

运行前需 source：`source install/setup.bash`

### release/

`build.sh` 打包产物 `install.tar.gz`，用于分发部署。已被 `.gitignore` 忽略。

## build.sh 脚本流程

1. 检查 ROS 环境（`ROS_DISTRO`）
2. 同步 git 子模块（如有 `.gitmodules`）
3. `colcon build --cmake-args -DCMAKE_BUILD_TYPE=Release`
4. 打包 `install/` → `release/install.tar.gz`

## install.sh 脚本流程

将 `install/` 内容按部署目录结构组织到 `debian/` 下，供打包 deb 用：
- 可执行文件 → `debian/.../home/dexforce/w1/dexe_recorder/`
- 依赖库 → `debian/.../home/dexforce/w1/install/`
